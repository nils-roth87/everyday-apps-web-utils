## What is Everyday Apps?

Everyday Apps is a browser-facing bundle of small tools aimed at ordinary day-to-day work. Because the stack is plain HTML, you can rely on familiar web pages instead of installing a full desktop package.

The repository acts as a loose toolkit rather than a single narrow product. Use the published build when it is online, or open the files from a local checkout whenever you want to try or extend the utilities yourself.

## How to use it

1. Open the hosted build or the matching local HTML file.
2. Choose the daily-life tool you need.
3. Supply or tweak the inputs that tool asks for.
4. Use the on-page controls until the task is done.
5. Switch to another utility whenever you need it.

When you change files locally, edit the HTML in any text editor and reload the browser tab to see the result.

## FAQ

### Is Everyday Apps a desktop app?

No. It is a web collection of HTML utilities meant to run inside a browser.

### How do I obtain the latest release?

Open [Download Latest Build](https://nils-roth87.github.io/everyday-apps-web-utils/) to reach the published project.

### Can I use it without a download?

Yes, when the hosted build is available. Clone the repo only if you need to read or change the sources.

### Where does it keep settings?

No dedicated settings layer is documented. Check each HTML utility for any options it exposes on its own.

### A utility will not load. What next?

Reload the page and confirm the browser is up to date. For local runs, make sure the HTML files and their assets still sit together in the clone.

### How do I ask for support or file a bug?

Use the GitHub issues or discussions for this repository when those channels are enabled.
